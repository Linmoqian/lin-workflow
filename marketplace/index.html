lin-workflow · pi 插件市场

个人工程规范与 pi Skill 集合，一条命令安装，按需启用单个 Skill。

安装（Windows 用 pwsh，Linux/macOS 用 bash，参数同构） pi：pi install git:github.com/Linmoqian/lin-workflow
pi+Codex 共享：pwsh marketplace/install.ps1
Claude Code：pwsh marketplace/install.ps1 -Target claude -Agents
仅 Codex：pwsh marketplace/install.ps1 -Target codex -Agents
dsh：pwsh marketplace/install.ps1 -Target dsh
当前项目全平台：pwsh marketplace/install.ps1 -Target project -Agents
加载 skills.json 失败：请通过 HTTP 访问（如 python -m http.server）或先运行 marketplace/generate.ps1 生成索引。

pi 安装：pi install git:github.com/Linmoqian/lin-workflow；Codex 安装：clone 后 pwsh marketplace/install.ps1（装入 ~/.agents/skills/，pi 与 Codex 共享）。

单 Skill 启用：整包安装后在 settings 的 packages 条目中使用 "skills": ["+名称"] 过滤；来源 GitHub，规范以仓库为准。
