# 机器人与具身系统安全工程规范

## 1. 适用范围与边界

本规范适用于具身智能、机器人、动力执行器、移动设备、机械臂、无人设备和人机协作系统的软件安全工程。

涉及安全相关任务时，先读取本规范，并按实现范围读取 [嵌入式开发](../embedded-dev/SKILL.md)、[C++ 开发](../cpp-dev/SKILL.md)、[并发与线程](../concurrency/SKILL.md)、[日志与终端输出](../logging-terminal/SKILL.md)、[验证](../verification/SKILL.md)、[代码 Review](../code-review/SKILL.md) 和适用的硬件、法规、客户标准。项目若涉及医疗、汽车、航空、工业安全或人员伤害风险，必须由具备资质的人员确认适用标准、等级、验证和签署要求。

本规范不能把未经评估的系统声明为安全，也不能用软件日志、模型置信度或仿真结果替代物理防护、急停和风险评估。

## 2. 安全目标与风险边界

- 明确保护对象：人员、设备、环境、数据和任务目标；记录不可接受的伤害、损坏和失控状态。
- 为每个系统定义安全边界、允许的能量、速度、力、温度、工作空间、载荷和操作环境。
- 安全目标必须可验证，例如“通信丢失后在规定时间内停止危险运动”，不得只写“提高安全性”。
- 安全监督的默认策略是拒绝危险命令、进入可预测安全状态并通知操作者；不能依赖上层模型自行判断。
- 安全约束优先级高于任务完成、性能、吞吐和用户便利性。
