# 接口文档可复制模板（api-documentation references）

## 9. 可复制模板

创建实际接口文档时复制以下模板，删除方括号提示；可选项确实不适用时写“不适用”。

````markdown

| 项目 | 内容 |
| --- | --- |
| 接口标识 | [command、事件名称或 METHOD /path] |
| 用途 | [一句话说明] |
| 调用方 | [调用模块或系统] |
| 提供方 | [Tauri 后端或后端服务] |
| 稳定性 | [实验性/稳定/已废弃] |
| 引入版本 | [版本] |
| 维护方 | [模块或团队] |
| 接口类型 | [Tauri：command/事件/channel；HTTP：HTTP API] |
| 调用方式 | [Tauri：同步/异步；HTTP：Method、Path、环境与 Base URL] |
| 权限或认证 | [capability/permission 或认证方式] |
| Content-Type | [HTTP 请求与响应类型；Tauri 写不适用] |

## 请求

| 字段 | 位置 | 类型 | 必填 | 默认值 | 约束 | 说明 |

| [稳定错误码或 HTTP 状态/业务码] | [触发条件] | [是/否/满足条件] | [调用方动作] |

## 权限与安全

[说明认证、授权主体、capability/permission、敏感字段和脱敏规则。]
````
